# Workflow: feature

Fluxo padrão para implementar uma nova funcionalidade neste projeto.

## Passos

1. Ler a tarefa, usando o template em `.riteward/templates/task.md`.
2. Explorar o código e a documentação relevantes.
3. Implementar a mudança em etapas pequenas.
4. Executar os scripts de test, lint e typecheck configurados.
5. Revisar a mudança antes de finalizar.

## Regras

- Não alterar arquivos fora do escopo da tarefa.
- Não pular os quality gates.
